2. ACTIONS TAKEN & ROOT-CAUSE ANALYSIS
--------------------------------------------------------------------------------
A. QUANTIFYING LABEL-NORMALIZATION IMPACT:
   - Evaluated `UNSW_NB15_testing-set.csv` (82,332 rows) and `UNSW_NB15_training-set.csv` (175,341 rows) under both the pre-fix and post-fix `_normalize_label` implementations.
   - Result: EXACTLY 0 rows were relabeled (0 changed from 0->1, 0 changed from 1->0).
   - Reason: In UNSW-NB15 dataset files, the `label` column is strictly integer `0` and `1` (or float `0.0`/`1.0`). In Python/pandas, these match `isinstance(val, (int, np.integer)): return int(val != 0)`, which was identical in both the pre-fix and post-fix code. The unhandled string fallback was never reached on the `label` column for numeric UNSW records.

B. ISOLATING THE TESTING-SET SCORE SWING (Limit vs. Fix):
   - The score drop observed during the previous task was caused 100% by the subsampling limit and striding (`--limit 10000` with `stride=8` vs `limit=30000` sequential flows).
   - When 30,000 sequential flows are evaluated, each entity accumulates ~118 consecutive flows in its history, allowing sequence models (Mamba-2, 1D-CNN, Autoencoder, and CfC LNN) to build rich temporal context across consecutive interactions.
   - When `--limit 10000` was run with `stride=8`, consecutive sampled flows jumped by 8 rows (and changed entities every jump), slashing the effective temporal history per entity to ~15 sparse interactions, which degraded recall across all temporal sequence models.

C. FULL-SCALE 30,000 FLOW RE-RUN:
   - Re-executed all 5 baselines (`hdc-lnn`, `mamba2`, `cnn`, `lstm`, `autoencoder`) on `UNSW_NB15_testing-set.csv` at the original full scale (30,000 flows, 4,613 test flows across 41 disjoint entities).
   - Manifold fitting executed strictly once per run on normal validation flows.
   - All predictions and drift scores were written to `runs/post_fix_30k_UNSW_NB15_testing-set_<model>/decisions.csv`.

D. INDEPENDENT SKLEARN RECOMPUTATION FROM RAW DECISIONS:
   - For all 5 baseline runs, loaded raw `decisions.csv` and recomputed Confusion Matrix, F1, Precision, Recall, AUROC, and PR-AUC using `sklearn.metrics.f1_score`, `precision_score`, `recall_score`, `roc_auc_score`, `precision_recall_curve`, `confusion_matrix`.
   - Verified that `metrics.json` matches `sklearn` recomputations with 0.000000 difference across all models.
