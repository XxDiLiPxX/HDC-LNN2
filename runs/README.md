# Runs

This folder is auto-generated by the evaluation harness (run_all_baselines.py, run_all_datasets.py). Each run folder contains config.yaml, metrics.json, decisions.parquet, and roc_curve.png.

Run artifacts are NOT committed to git by default — they're regenerable. To reproduce a run, re-run the harness with the same config.

If you want to preserve a specific run as a citable reference (e.g. for a report), it must be force-added explicitly:
  git add -f runs/<run_folder_name>/
