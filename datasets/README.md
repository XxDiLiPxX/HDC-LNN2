# Datasets Directory

This folder holds the cybersecurity benchmark flow datasets used for training, evaluation, and empirical comparison across all models.

## Pre-Packaged Benchmark Datasets
Datasets are included directly in this repository to enable immediate out-of-the-box evaluation and reproduction:
- **UNSW-NB15**: `UNSW_NB15_testing-set.csv` (primary 30k flow evaluation benchmark) & `UNSW_NB15_training-set.csv`
- **KDD & NSL-KDD**: `kdd_test.csv`, `kdd_train.csv`, `NSL_KDD_Test.csv`, `NSL_KDD_Train.csv`, `kddcup99.csv`
- **ToN-IoT**: `ton-iot.csv`
- **IoT-23 / Botnet**: `dataset1.csv` through `dataset23.csv`, `UNSW_2018_IoT_Botnet_Dataset_*.csv`
